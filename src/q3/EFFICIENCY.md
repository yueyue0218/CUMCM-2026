# Q3 集中测量与联合路线

当前默认策略为 `efficient`，不需要模型文件。它使用已知物理规则、Q1定位及清除认证、同站集中测量和滚动路线。原 complete、planner、ppo、hybrid 保留作对照，原训练模型仍可显式加载。

本页保留首次三策略分层验收。当前实现文件已改名为 `experiment_joint_routing.py`；新增的五类对照及最新六策略表见 [对照说明](STRATEGY_CONTROLS.md) 和 [具名结果表](../../results/tables/Q3_实验组与对照组_策略比较表.md)。

## 运行与复现

官方Q3演练接口就绪后，从仓库目录执行：

```powershell
python -m src.q3.main --robot-id "当前登录队号"
```

也可显式指定 `--strategy efficient`。原组合策略使用 `--strategy hybrid --checkpoint <模型路径>`，原基线为 `--strategy complete`。本轮没有连接官方模拟器或使用正式测试机会。

分层离线比较：

```powershell
python -m src.q3.evaluate_efficiency --cases-per-group 20 --seed 70260912 --checkpoint "runs/q3/training/20260912T163625_420414+0800_ppo/best.pt"
```

## 实现变化

1. 原点先集中检测频道，再用250米共享基线为多个已发现频道补测，避免发现一个源就离开并返回扫频。
2. 将Q1认证清除点、待补测源的位置估计、必要覆盖站点放入同一条开放路线。多起点最近邻加2-opt优化顺序，每次执行首个任务后更新。
3. 单次示向的补测带横向偏移；接近位置估计时优先利用当前站点。沿途只对当前目标、靠近估计位置或交会角明显变化的频道补测，减少重复检测。
4. 依据新增覆盖与插入路线的额外距离安排覆盖停靠点。网格样本及假想目标点仅用于评分，不能作为真实清除或无源证据。
5. 真实覆盖认证递归细分目标圆盘外包方格。只有“格中心距某实测站点＋半对角线≤1000米−1毫米”时才认证整格覆盖；圆盘外的格子跳过，细分上限仍不确定则不认证。所有未发现频道必须有这些站点的实际无信号回执。
6. 发现16个不同源后按题设上限排除其余未知频道，继续清除已发现源；发现10、12、14个不会触发这一捷径。
7. 单频道8次调度仍未就绪时用解析后备，全局256轮后执行固定布局和剩余源后备。每步保留现实/虚拟预算与串行协议检查，清除仍要求Q1、near或解析距离上界支持。

开发场景从60260912起；独立验收分别使用70260912、70261912、70262912、70263912起的20个种子。开发阶段比较过环半径、扫频间距、共享基线及粒子均值估计；最终冻结几何中心、250米初始共享基线、1500米额外全扫间距等配置。本轮没有用新测试集调参或重新训练旧PPO。

## 产物与限制

- 实现：`experiment_joint_routing.py`、`coverage_control.py`；评估：`evaluate_efficiency.py`。
- 汇总：`results/tables/q3_efficiency_stratified.json`、同名CSV。
- 归档：`runs/q3/efficiency/20260912T173628_929912+0800_stratified/`，包含源码快照、配置、每场输入与全部动作、独立成本核算及报告。
- 摘要分别记录动态覆盖或源数上限的停止依据，保存全扫站点和逐频道无信号回执，不将未访问点或预测分支写成实测证据。

四组中任一场景失败则不报告综合速度分数；失败、退出异常及未确认请求也保存现场。覆盖和Q1采用带工程余量的浮点计算，不是严格区间证明。源码快照对应实验实际版本，后续入口和失败日志改进不追溯改写历史快照。

新策略无需PPO训练即可运行。已有训练操作见 [TRAINING.md](TRAINING.md)；本轮源码变化后，续训旧目录需显式加 `--allow-code-change`，以归档当前实现并重新评估原验证集。
