# Q3 训练、续训与比较

后续调度改进现已作为默认 `efficient` 策略，分层结果见 [EFFICIENCY.md](EFFICIENCY.md)。本文训练实验保留为历史对照；efficient无需模型。

当前已接通完整本地训练链路。模型从可观测历史选择检测点、频道或认证清除动作；完整任务耗时作为学习目标，有限探索结束后仍把全部后备清除成本计入回报。可以保存模型、恢复训练，并在实际入口加载同一套候选策略。

## 已接入的算法与模型

| 层次 | 当前代码实现 |
| --- | --- |
| 搜索与安全后备 | 七点覆盖、蛇形频道扫描、逐频道完整排除证据；示向轴有限步收缩，near 或 Q1 认证清除 |
| Q1 几何 | 目标圆/测向扇区/接收距离的凸外包交集、最小包围圆与独立最大距离核验；复用公共实现 |
| Q2 主动候选 | 横向、纵向补测点；复用 Q2 凸多边形采样和接收概率工具 |
| 世界模型 | 已发现频道的位置—固定半径粒子后验；融合 direction/near/no_signal；近似响应分支与预期定位尺度 |
| 清除路线 | 开放路径动态规划（不超过10点）；更大规模使用最近邻与有界 2-opt |
| 策略网络 | 共享频道编码、均值聚合、GRU记忆、可变长度候选策略头、状态价值头；当前没有注意力层 |
| PPO训练 | gamma=1、GAE、概率比裁剪、熵项、梯度限制、KL联合回滚；每轮完整重算循环序列 |
| 模仿预热 | 规划器示范单独做监督初始化，不混入 on-policy PPO 轨迹 |
| 组合策略 | 单步世界模型/路线启发式评分，加 PPO 对数概率排序先验；价值头目前用于训练，未接入多步树搜索 |

粒子概率用于排序，不能替代 Q1 清除认证或完整覆盖证据。不同站点误差在预测中使用独立连续近似，尚未对量化、固定空间相关误差校准；未知频道没有完整占用概率模型。当前实现支持实验迭代，不等于论文所有优化扩展都已完成。

## 开始新训练

以下命令从仓库根目录执行。本机已安装 CPU PyTorch，当前未检测到可用 CUDA；训练入口使用 CPU，默认单线程。不需启动官方模拟器。

```powershell
python -m pip install -r requirements-training.txt
python src/q3/train_ppo.py --episodes 200 --warmup-episodes 16 --batch-episodes 4 --epochs 3 --hidden-size 64 --free-actions 64 --validation-cases 4 --seed 20260912
```

已具备依赖时可省略安装。训练输出独立目录 `runs/q3/training/<时间>_ppo/`。这里的200是实际 PPO 回合数，16个示范预热回合另计；属于可调整起点，不是收敛保证。`--free-actions` 限制自由决策步数，`--free-time-s` 限制自由阶段虚拟时间，达到限制后执行完整后备。`--prediction-limit`、`--particle-count` 控制预测计算量。`--source-count` 仅供课程/调试，默认训练及验证为10—16源。

默认合成分布：源数在10—16均匀抽取，频道子集均匀抽取，位置在1800米圆盘按面积均匀，接收半径在1000—1500米均匀。误差为场景固定的有界位置函数，读数保留两位小数且最终误差仍在±1°内；同点复测不重新抽误差。源位置、总数和场景种子不进入策略特征。只有逐频道观测与成功清除证据决定终止，隐藏真值仅用于环境生成及终止后的独立核对。

每步奖励为 `-Δ虚拟时间/1000`；未完成额外罚100。强制后备动作只训练价值、不计算策略梯度，但其全部耗时仍进入自由阶段回报。不能在自由预算耗尽时截断回合，也不能将 planner/hybrid 动作冒充 PPO 自身采样。

## 继续已有训练

本次产物目录：`runs/q3/training/20260912T163625_420414+0800_ppo/`，含16个示范回合与70个 PPO 回合。继续增加200个 PPO 回合：

```powershell
python src/q3/train_ppo.py --resume "runs/q3/training/20260912T163625_420414+0800_ppo" --episodes 200 --batch-episodes 4 --epochs 3 --allow-code-change
```

续训恢复 last 权重、优化器、随机状态、训练种子、环境配置及原验证集；`--episodes` 表示本次追加回合数。环境结构参数以保存配置为准，若需改变自由预算等实验条件，开启新训练。源码哈希变化时默认拒绝；确认要使用修改后的算法续训，可加 `--allow-code-change`，程序归档新源码并在原验证集重新评估 incumbent，保留各段来源。续训中模型加载消耗的随机数不会改变恢复后的采样起点。

| 文件 | 用途 |
| --- | --- |
| `config.json` | 初始超参数、分布、种子与源码哈希 |
| `training.jsonl` | 每次预热/更新的损失、KL、成功数、时间和固定验证集成绩 |
| `initial.pt` | 示范预热完成、PPO更新前的模型 |
| `last.pt` + `training_state.pt` | 最新模型及优化器/随机状态，成对用于续训 |
| `best.pt` | 固定验证集全清除且平均时间最小的候选模型 |
| `trajectory_sample.npz` | 首个 PPO 回合的原始特征快照、动作、旧概率/价值与全部尾段奖励 |
| `source_snapshot*.zip` | 原训练及换代码续训时的实际源码，包含所依赖的Q2实现 |

best 的权重可以早于最后回合，但测试隔离按整个选模过程接触的场景计算。换代码复评放在 `current_selection_assessment`，原权重训练哈希保留。中断后需要核对 last 与优化器回合一致，程序会拒绝不一致状态。

## 独立对比

```powershell
python src/q3/evaluate_policy.py --checkpoint "runs/q3/training/20260912T163625_420414+0800_ppo/best.pt" --cases 12 --seed 50260912
```

每个场景固定后依次运行 complete、planner、ppo、hybrid。输出 `results/tables/q3_policy_comparison.json` 与同名 CSV。种子与全部 PPO训练、示范预热、验证选模场景重叠时拒绝执行。失败场景不计为更快；报告另列成功数、成功配对数。若根据本次结果继续调整算法，下一轮验收应换用事先确定的新测试种子，避免反复调参污染测试集。

2026-09-12 结果，独立种子50260912—50260923：

| 策略 | 全清除 | 平均总虚拟时间（秒） | 相对基线的逐场改善率均值 |
| --- | --- | --- | --- |
| complete | 12/12 | 8342.23 | 0% |
| planner | 12/12 | 8363.77 | −0.25% |
| ppo | 12/12 | 11727.19 | −40.98% |
| hybrid | 12/12 | 8095.13 | +2.83% |

hybrid 在11/12场景优于基线，按两个平均时间之比计算降低2.96%；与“逐场改善率取平均”的2.83%口径不同。纯 PPO 当前仍较慢，模型未证明收敛。该小样本结果支持继续验证组合策略，不足以证明普遍优越；该历史实验时默认仍为complete，当前默认已更新为efficient。best 权重来自第12个 PPO回合，经过共70回合选模暴露；初始至最后权重参数变化的L2范数约4.7835，已实际更新参数。

这些均为本地合成结果，没有使用官方演练或正式测试机会。离线误差场不代表官方内部机制，现实执行耗时也需联调验证。

## 加载模型运行

在官方界面准备好Q3演练后，可执行：

```powershell
python src/q3/main.py --robot-id "当前登录队号" --strategy hybrid --checkpoint "runs/q3/training/20260912T163625_420414+0800_ppo/best.pt"
```

改为 `--strategy ppo` 可运行独立策略网络；`--strategy planner` 不需要 checkpoint；`--strategy complete` 使用确定性基线。入口在进入模拟器前检查模型特征版本，推理共用训练候选与已保存配置。清除认证、成功回执、现实/虚拟预算及未确认请求处理始终有效。运行说明及日志口径见 [README.md](README.md)。
