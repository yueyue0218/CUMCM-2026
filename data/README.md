# 数据说明与数据字典

本题核心输入来自在线模拟器交互，运行记录应放在 `runs/`，不要把 `data/` 当作 Q3/Q4 日志目录。本目录仅保留确有需要的自主数据或可复现中间数据。

## 目录约定

- `raw/`：从官方附件或外部来源提取的原始数据。程序只能读取，不能覆盖。
- `processed/`：清洗、转换、合并后供模型直接使用的数据。
- 临时调试数据尽量不提交；有价值的中间结果写入 `processed/` 并注明生成方式。
