# Q1 几何定位求解器设计

## 1. 目标与范围

本改动为问题一提供可运行、可验证、可复现的通用几何求解器。输入是同一干扰源的若干检测点坐标、示向度和误差半角；输出是交会定位区域的状态与顶点、区域直径及最远点对、以最远点对为直径的圆是否覆盖定位区域、最小包围圆，以及面向后续问题的 20 米清除保证状态。

问题一的主结果针对纯测向半平面交多边形 `P`。半径 1800 米目标圆域、有效接收状态和 5/20 米物理规则作为显式可选约束与下游接口处理，不能悄悄改变问题一的多边形口径。

## 2. 备选方案与选择

采用“现有 SciPy 认证区域状态，核心几何算法自行实现”的方案：用二维线性规划检查半平面系统是否可行并分别求坐标上下界；对有界区域，以这些有限界构造初始矩形，再用增量多边形裁剪得到交集。凸包、旋转卡壳、格林公式、Welzl 最小包围圆和覆盖判定均在仓库内实现。

不采用完全自写二维线性规划，因为它显著增加退化、无界和数值稳定性的证明与测试负担；不引入 Shapely，因为新依赖会掩盖论文附录需要展示的核心算法。

## 3. 模块划分

- `src/q1/geometry.py`：数据类、示向楔形到半平面的转换、二维区域可行性和有界性认证、Sutherland-Hodgman 增量半平面裁剪、凸包规范化。
- `src/q1/measures.py`：穷举直径、旋转卡壳、直径圆覆盖检查、直线段和有向圆弧的格林积分、组合边界面积与质心。
- `src/q1/enclosing_circle.py`：固定种子的 Welzl 随机增量最小包围圆，处理空集、单点、重复点、共线和近共线输入，并在返回前复核全部点。
- `src/q1/solver.py`：组合各模块并生成结构化结果；分开报告题目多边形结论和可选物理约束结论。
- `src/q1/main.py`：从 JSON 读取一个或多个案例，写出 JSON 结果；所有路径相对仓库根目录。
- `src/q1/simulate_cases.py`：以固定随机种子生成可复现的常规与边界案例，调用同一正式求解器并导出机器可读结果和 Markdown 摘要。

模块只通过明确的数据类和纯函数通信；仿真脚本不得复制另一套求解算法。

## 4. 输入与输出契约

单个观测包含 `station=[x,y]`、`bearing_deg` 和可选 `half_angle_deg`，默认半角为 1 度。所有坐标单位为米，角度输入为度并归一到 `[0,360)`；非有限坐标、非有限角度、非正或不小于 90 度的半角均拒绝。

区域状态取 `empty`、`unbounded`、`point`、`segment` 或 `polygon`。只有非空有界状态输出有限直径；空集直径为 `null`，无界区域直径为正无穷的 JSON 兼容状态字符串。退化区域分别按点和线段精确处理。

覆盖输出同时包含：直径、最远点对、直径圆圆心和半径、全顶点最大距离、是否覆盖；最小包围圆另列圆心、半径和最终最大残差。控制输出显式给出 `clearance_margin_m = clear_radius_m - rounded_center_max_distance_m`，空集或无界区域为 `null`。`CLEAR_READY` 只在实际输出圆心对选定待覆盖集合的可靠最大距离不超过 20 米时返回，否则区分 `SINGLE_DISK_IMPOSSIBLE` 与 `COVERAGE_UNCERTAIN`。

## 5. 数值策略

- 线性规划使用未经任意大包围盒截断的原始半平面系统，只负责可行性与坐标极值。
- 多边形裁剪使用线性规划得到的有限坐标界，并以统一绝对/相对容差判断边界包含；所有返回点再次验证全部原始不等式。
- 距离先比较平方，最终展示时才开方；旋转卡壳结果必须与独立的全顶点对穷举一致。
- 最小包围圆使用固定种子 `20260911` 的迭代随机增量算法，三点圆采用尺度相关共线判据；若结果不能覆盖全部点则明确报错，不返回未认证圆，也不依赖 Python 递归深度。
- 20 米阈值比较使用距离平方并记录裕量，避免显示舍入改变结论；发送坐标与内部最优圆心分开保存。
- 有向圆弧保存起角与逆时针扫角，允许扫角为 0 或 360 度，不通过两个 `atan2` 值猜测短弧。

## 6. 仿真数据与边界矩阵

仿真分为两组。确定性边界组包含：跨 0 度测向、误差恰取正负 1 度、空交集、无界交集、单点、线段、近平行交会、重复观测、锐角三角形的直径圆失败、正方形的直径圆成功、20 米恰好可覆盖、超过阈值的微小扰动、源位于 1800 米边界、圆弧跨角度割缝及输出圆心舍入反例。

随机组使用种子 `20260911`。每例先在目标圆域内生成真实源位置和分散检测点，再对真实方位加入 `[-1,1]` 度有界误差；验收不变量是每个一致案例的真实源都落在所得区域闭包中。随机组同时包含传感器几何较好和近平行两类布局，以比较直径与交会角的关系。

参数写入 `data/processed/q1_simulation_parameters.md`，并保存机器可读案例 `data/processed/q1_simulation_cases.json`。结果写入 `results/tables/q1_simulation_results.md` 和 `results/tables/q1_simulation_results.json`。Markdown 结果报告样本数、状态分布、直径与半径统计、真值保留率、旋转卡壳对照差异、Welzl 覆盖残差和所有边界案例结论。

## 7. 测试与验收

采用标准库 `unittest`，测试文件放在 `src/q1/test_*.py`，避免增加仅供测试使用的依赖。每个生产函数先写会因功能缺失而失败的测试，再写最小实现。

验收条件：

1. 所有正常输入的裁剪顶点满足每个半平面约束，状态分类与解析例一致。
2. 旋转卡壳直径与穷举法在固定随机凸多边形及退化案例上相同。
3. 格林公式结果与圆盘、半圆、扇形和多边形解析值在声明容差内一致。
4. Welzl 圆覆盖全部输入点，半径处于 `D/2` 与 `D/sqrt(3)` 之间，并通过解析三角形、正方形和共线点案例。
5. 所有一致仿真案例保留真实源；故意冲突案例必须识别为空集。
6. 两份 Markdown 文档可由仿真脚本确定性重建，重新运行后 Git 工作区无变化。
7. 完整测试、入口示例、仿真生成和差异检查均以退出码 0 完成。

## 8. 提交与协作

分支为 `q1/geometry-solver`，基线为 `main`。提交按设计、测试与核心算法、求解入口、仿真数据与报告、最终文档整理拆分；每次只暂存明确文件。推送前重新核对 Author、Committer 和 GitHub 凭据，最终创建面向 `main` 的 Pull Request。现有 `q1/baseline-model` 与未跟踪 Q2 文件不纳入本分支。
