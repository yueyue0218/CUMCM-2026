# 正式测试前检查

Q3、Q4 正式测试各只有 3 次机会，启动后中止也会消耗次数。每次正式测试单独复制本清单并由执行人和复核人共同确认。

## 代码与版本

- [ ] 当前分支为 `main`
- [ ] `git status` 干净
- [ ] 已记录当前 commit hash
- [ ] 已创建或确认版本标签 `q3-formal-vN` / `q4-formal-vN`
- [ ] 代码版本已冻结，测试期间不临时改策略
- [ ] 所有关键测试通过
- [ ] 最近已完成多次对应问题的演练
- [ ] 演练日志可复盘，统计口径与论文一致

## 程序安全

- [ ] 无明显死循环和无上限重试
- [ ] 无异常高频 HTTP 请求
- [ ] 不并发发送不同动作
- [ ] `request_id` 唯一性及幂等重试逻辑通过
- [ ] 同时检查 HTTP 状态和 `accepted`
- [ ] 正确处理 `direction`、`near`、`no_signal`
- [ ] `near` 不读取 `svd_deg`，`no_signal` 不直接判定频道不存在
- [ ] `/clear` 不改变当前检测频道
- [ ] 使用 `/enter` 返回的 `remaining_real_duration_s`
- [ ] 已设置保守的主动 `/exit` 时间余量
- [ ] robot_id 配置为当前登录参赛队号

## 模拟器与环境

- [ ] 模拟器账号登录正常且未在另一设备占用
- [ ] 网络连接稳定
- [ ] 本机时间与服务器时间差不超过 60 秒
- [ ] 界面已进入正确的 Q3 / Q4 正式测试模块
- [ ] 当前正式测试剩余次数已确认
- [ ] 已等待界面显示机器狗接口就绪后再调用 `/enter`
- [ ] 本次运行日志保存路径已确认
- [ ] 官方日志上传队列和磁盘空间正常

## 测试后归档

- [ ] 已主动结束或记录实际结束原因
- [ ] 已导出官方加密日志且未修改文件名
- [ ] 官方日志已放入对应 `support/q3_official_logs/` 或 `support/q4_official_logs/`
- [ ] 已记录测试案例编码
- [ ] 已记录清除干扰源个数
- [ ] 已记录平均定位清除时间
- [ ] 已记录程序运行时间
- [ ] 已记录对应 Git commit hash 和版本标签
- [ ] 已更新论文正式测试结果表
