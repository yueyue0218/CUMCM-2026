# B题问题依赖与最小闭环

## 1. 问题依赖关系

Q1 → Q2
Q1 + Q2 → Q3
Q3 → Q4

说明：
- Q1 提供定位区域计算工具；
- Q2 提供第二检测点选择策略；
- Q3 组合搜索、定位、清除；
- Q4 在 Q3 基础上处理定向源。

## 2. 每问的最小可运行闭环

### Q1
输入检测点与示向度
→ 构造定位区域
→ 计算直径
→ 判断圆覆盖

完成标准：
能够对任意合法输入给出结果。

### Q2
输入第一检测点与示向度
→ 生成第二检测点候选区域
→ 给出选择规则

完成标准：
能输出明确候选区域和选择依据。

### Q3
搜索
→ 检测
→ 定位
→ 清除
→ 判断是否继续

完成标准：
能够在模拟器中完成一轮完整自动流程。

### Q4
在 Q3 基础上
→ 处理定向源 no_signal 歧义
→ 多方向观测
→ 完成混合源搜索清除

完成标准：
能够处理全向与定向混合环境。
