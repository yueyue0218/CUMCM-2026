# Q3 分层评价与调度效率改进

目标（用户修订）：在全部清除及完整无遗漏证据下尽量降低时间，不硬凑200秒；10、12、14、16源分别评价，四组每源均值等权平均。使用既有Q1认证与串行客户端，保留旧模型及实验，不通过读取隐藏真值或提前截断改善指标。

用户已批准的方向：集中扫频、联合定位与清除路线、沿途观测、后备仅处理难例。比较仅增加PPO训练、全扫后逐源清除、联合滚动路线三种方案，选择第三种；前两种保留为对照。

- [x] 新增 `src/q3/experiment_joint_routing.py`：同站多频道测量；Q1位置估计及认证缓存；覆盖/补测/清除位置的开放路线，滚动执行第一步；有限停滞后备。
- [x] 新增 `src/q3/coverage_control.py`：用方格单元的距离上界与自适应细分，保守认证任意实测站点对1800米圆盘的1000米覆盖；不足时继续已知有限布局。只能使用各未知频道都有有效无信号回执的站点。
- [x] 新增 `tests/test_q3_experiment_joint_routing.py`：覆盖空洞、边界与完备性；同点集中测量；多源位置、±1°固定误差、通信失败与预算退出；近距离清除必须依据实际回执。
- [x] 新增 `src/q3/evaluate_efficiency.py`：总时间、每源时间、移动/检测/切频/清除分解、源数分层、完整输入场景及源码哈希；开发种子60260912起，冻结后验收种子70260912起，旧12场只作历史对照。
- [x] 实验驱动改进调度；新策略接入 `main.py`，旧模型仍可加载。若独立验证达标再将新策略设为默认。
- [x] 完成所有回归、独立代码审查和使用文档。目标是小样本独立验证的平均效率，不承诺每场都不超过200秒或官方成绩。

测试顺序：先覆盖几何与协议约束的失败测试，再实现最小闭环，开发场景分析主要移动成本，最后冻结参数运行新测试集。代码归src/q3、测试归tests、生成表归results/tables、详细日志与配置归runs/q3/efficiency。

验收：80个独立场景、三策略240次全部清除。四组等权每源时间由旧hybrid的608.1秒降至257.2秒；各层均改善。新策略设为默认，旧模型保留，操作见 src/q3/EFFICIENCY.md。
