# 模型假设

本文件依据题面、附件及用户给出的八条设定整理。以下区分新增概率假设、直接采用的题设条件和数值实现约定；状态为 `REVIEW`，待队友独立复核。概率假设供问题二至四的预测评价与自主场景实验使用，问题一的硬界几何结论不依赖均匀分布或误差独立性。

## 一、采用的新增假设

记目标圆域为 \(\Omega=\{G:\|G\|\le1800\}\)，第 \(k\) 个源的位置、有效接收半径和定向朝向分别为 \(G_k\)、\(R_k^{\mathrm{rec}}\)、\(\beta_k\)。下列分布均为观测前的场景先验，场景生成后各源参数在一次测试内保持不变，不在每次检测时重新抽取。关于不同源的假设均以给定源总数及类型构成为条件，并不意味着机器狗知道其具体取值。

| 编号 | 假设 | 适用问题 | 建模理由与影响 | 待执行的验证或敏感性分析 |
|---|---|---|---|---|
| A1 | 各源位置在目标圆域内按面积均匀分布，即 \(G_k\sim\mathrm{Unif}(\Omega)\) | q2–q4概率评价与场景实验 | 缺少空间偏好信息时采用对称基准先验；会影响期望定位收益和搜索效率，不影响硬界区域包含性 | 与中心集中、边缘集中和聚集分布比较清除比例及总虚拟时间 |
| A2 | 各源有效接收半径服从 \(R_k^{\mathrm{rec}}\sim\mathrm{Unif}[1000,1500]\) 米 | q2–q4 | 区间为题设条件，均匀分布为新增近似；影响接收概率与无信号结果的权重，不要求半径互不相同 | 比较偏短、偏长的半径分布及1000/1500米边界场景 |
| A3 | 对定向源，朝向服从 \(\beta_k\sim\mathrm{Unif}[0,2\pi)\) | q4 | 缺少优先发射方向时采用旋转对称先验；仅适用于定向源，不为全向源人为定义有效朝向 | 比较朝向集中和不同定向源占比的场景 |
| A4 | 各源的位置、接收半径及适用的定向朝向在先验中相互独立；频道分配整体与上述物理参数独立，并严格满足不同源频道不重复 | q2–q4 | 用无参数关联的基准模型组织场景先验；频道之间因不重复要求而不独立，不能逐源独立抽取频道 | 比较位置与半径相关、相邻源朝向相关的情形；检查频道分配无重复 |
| A5 | 对同一源，在不同检测位置采用测向误差相互独立的工作近似；同一位置的误差只取一次并固定复用 | q2–q4概率评价 | 独立性是对不同位置误差统计规律的简化，题面没有保证它；邻近位置存在相关误差时可能高估新观测收益 | 比较空间相关误差与独立误差下的策略表现；确认原地重复检测不产生新独立样本 |

圆域均匀指单位面积上的密度相同，不是距原点的径向距离均匀。A1可明确写为

\[
p_0(G)=\frac{\mathbf1_{\{G\in\Omega\}}}{\pi\,1800^2},\qquad
G=1800\sqrt U\,(\cos(2\pi V),\sin(2\pi V)),
\quad U,V\overset{\mathrm{iid}}\sim\mathrm{Unif}[0,1].
\]

**先验不等于后验。** 对有效观测历史 \(H\)，位置后验满足

\[
p(G\mid H)=\frac{p(H\mid G)p_0(G)}{\int_\Omega p(H\mid X)p_0(X)\,\mathrm dX}.
\]

其中似然需要处理未知接收半径、定向朝向及误差等量。观测后位置一般不再均匀，各参数也可能产生后验相关性。因此，不能在每次裁剪后自动重置为当前外包均匀分布，也不能自动把外包质心当作后验期望。

**尚未补充的概率设定。** A5和误差硬界没有规定误差的密度，也不意味着误差在[-1度,1度]内均匀。源总数、占用频道组合、定向源数量或类型构成的概率分布也未在本文件中指定。只有具体期望计算涉及这些未知量时，才须补充相应分布或采用条件计算；在此之前可使用无需这些概率的最坏情形几何指标，不得把尚未给出的似然当作已知。

## 二、直接采用的题设条件

下列内容作为模型条件使用，不重复列为新增假设。依据：[B题题面](../problems/B/B题.pdf)、[附件1](../problems/B/attachments/附件1.docx)、[附件2](../problems/B/attachments/附件2.docx)。

| 编号 | 条件与明确口径 | 算法含义 |
|---|---|---|
| F1 | 按题设硬界口径，将最终有效示向度读数与真实方位的环形角差限制在[-1度,1度] | 同源有效测向的半角1度楔形在精确计算下包含真实位置；数值实现仍需认证外包，不把此结论解释为测向误差均匀 |
| F2 | 同地点的环境误差在测试期间固定；同一未清除源的物理参数保持不变 | 相同位置重复检测同一源应得到相同测向读数；重复观测不能缩小硬误差界或作为新的独立样本 |
| F3 | 各源频道互不相同且不变，信号互不影响；一次仅检测一个频道 | 若收到信号，只来自对应频道的源；仍可能返回no_signal或near，没有多源叠加 |
| F4 | 机器狗沿直线以5米/秒移动，移动中不检测；换频道1秒，检测5秒，光学定位3秒，激光清除2秒 | 路线由直线段构成；清除成功耗时5秒，失败仍耗时3秒，另计移动；按题设计时，不另加加速、转向和启动耗时 |
| F5 | 光学定位及清除只受20米距离条件限制，与源辐射朝向无关，包含20米边界 | 无信号不必然意味着不能清除；near只在满足信号接收条件且距离不超过5米时返回，可为当前位置提供清除依据 |
| F6 | 初始已知题设及选定先验，未知具体场景参数 | 已知目标圆域、20个候选频道、接收半径范围及问题三/四的总数10—16；未知实际个数、占用频道、位置、半径和定向信息，须通过合法观测推断 |
| F7 | 虚拟时间不超过100小时；提交坐标各分量绝对值不超过2000000米；现实运行受进入后最多20分钟与25分钟窗口共同限制 | 这些仍是执行约束，通常不活跃不等于可以删除；使用接口返回的实际剩余时间。源位置受1800米圆域限制，机器狗可以在圆域外移动 |

F1的角度条件为

\[
\left|\operatorname{wrap}_{[-180^\circ,180^\circ)}(\theta_i-\alpha_i)\right|\le1^\circ.
\]

主模型采用最终读数硬界对应的1度半角。原文中的1.005度仅保留为“有界误差后另行舍入”解释下的工程比较情景，不在这一口径下重复叠加。接口舍入机制或观测一旦与硬界解释不符，应核查并修正模型口径，不能静默丢弃矛盾数据。

问题三、四以**确保所有干扰源清除为前提，最小化包含全部动作的总虚拟时间**。不采用“时间和位置上限不存在”的假设，不把提前结束测试当作缩短完成时间。

## 三、几何与数值实现约定

| 编号 | 约定或条件 | 影响及复核方法 |
|---|---|---|
| Q1-C1 | 主模型按F1采用最终读数的1度硬界；1.005度仅作为另外舍入解释下的工程比较情景 | 不在主模型中重复计量化误差，不宣称工程裕量覆盖任意截断规则 |
| Q1-C2 | 同地误差固定为题设事实 | 重复原地观测不能缩小误差界 |
| Q1-C3 | 全部干扰源位于1800米圆域为题设事实；下游K必须与圆域取交 | 圆弧参与直径、面积、质心及覆盖计算，包围盒不是圆域 |
| Q1-C4 | 有理数只对近似系数精确；外包需另有方向/残差误差界 | 正文式（13）给出有界圆域内的保守半平面；任何数值裕量均需证明其覆盖系数误差 |
| Q1-C5 | A1给出目标圆域上的均匀先验；当前定位外包仍是几何对象，不自动具有均匀后验 | 只有选定区域上的条件分布确实均匀时，该区域质心才等于条件期望；清除始终使用全域覆盖判据 |
| Q1-C6 | 为维持凸性，direction的5米内排除、部分no_signal距离排除及未知定向信息单列 | K是保守定位外包，后续不能称其已融合全部信息；near仍与既有区域取交 |
| Q1-C7 | Jung是针对同一非空紧致集合的几何定理，不是新增假设；Welzl用于有限点最小圆 | 预判存在性与指定圆心覆盖分开；数值上下界必须可靠且针对同一集合；外包排除不得反推真实源无法清除 |
| Q1-C8 | 圆弧以逆时针起角、扫角及整圆标记表示，几何裁剪决定保留弧侧 | 属于表示约定；跨零/正负π展开，保留大于π的长弧；积分不得使用最短角差 |
| Q1-C9 | 目标圆盘内含圆周对踵点可直接确定D=2R | 属于几何推论；两点须属于融合后的待测区域，不能以数值外包点证明原集合直径 |
| Q1-C10 | 面积缩减是凸外包的几何指标，期望准则需另建观测概率模型 | 不等同于Shannon信息增益；纳入near/no_signal，排除不可能结果，零面积改用长度指标 |
| Q1-C11 | 控制状态以已确认未清除源及可靠几何证据为前提 | 上界认证具体清除位置、下界排除整个所选区域；证据不足返回未确定；多点方案需证明圆盘并覆盖全域 |
