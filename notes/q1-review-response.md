## Welzl与Jung专项审核

| 检查点 | 已落实的限制或结论 |
|---|---|
| 三类判断区分 | 直径圆覆盖、20米圆存在性、指定输出位置覆盖分别判断 |
| Jung使用范围 | 同一非空紧致平面集合满足D/2≤r_*≤D/√3；未裁剪无界P不能使用有限界 |
| 充分与必要条件 | D≤20√3保证存在，D>40排除整个所选集合的20米覆盖，中间区间须求解；平方界为1200/1600 |
| 外包与真实集合 | 外包可覆盖能保证真实位置；外包不可覆盖不能反推真实可行集不可覆盖，更不代表某次清除必然失败 |
| 定理不能指定圆心 | Jung上界可缩小最优半径区间，不自动关联已知圆心；最终使用实际输出位置的全域距离上界 |
| 最优值一致性 | 半径位于Jung区间不证明覆盖或最优；D和r以及所有数值界必须针对同一集合 |
| Welzl子问题 | 区分三点最小圆与强制三点在圆周的圆；不把钝角三点的最长边圆用于不相容的强制边界集 |
| 共线与数值判定 | 三个不同共线点不存在有限外接圆；近共线须可靠判断，不能任意合并；固定随机种子仅帮助复现 |
| 圆弧处理 | 有限点Welzl后继续检查圆弧内最远点并增补；不以圆弧端点代表整段弧，不宣称整体期望O(m) |
| 半径上下界 | 有限点最优半径可靠下界与当前中心全域覆盖上界分开；一个近似可行圆半径不能用作最优值下界 |
| 停止条件 | 输出近似最小圆要求当前中心的覆盖上界减最优值下界满足精度；仅Jung收紧后的最优值区间够窄，不能宣称已找到同精度圆心 |
