# 最终论文与提交检查

最终 PDF、Word 版本及最终支撑材料清单放在这里。不要存放临时编译文件。

## 匿名与格式

- [ ] 电子论文第一页为摘要页，不包含承诺书和编号页
- [ ] 摘要含标题和关键词，原则上不超过一页
- [ ] 正文不设目录且不超过 30 页，附录列出支撑材料文件
- [ ] 论文、源码、注释、文件名和元数据中无姓名、学校、赛区等身份信息
- [ ] 引用、外部数据来源和第三方代码已注明

## 内容与复现

- [ ] q1–q4 均被逐项回答，摘要给出主要量化结果
- [ ] 论文中的最终数字、图表与 `results/` 一致
- [ ] 随机种子、关键参数、软件环境和运行命令已记录
- [ ] 在另一台电脑完成一次独立复现
- [ ] 支撑材料包含必要源码、自主查阅数据和中间结果
- [ ] Q3/Q4 各三次正式测试结果均可追溯到 commit、版本标签和 `runs/` 记录
- [ ] 已完成 `docs/formal_test_checklist.md`，官方加密日志位于 `support/` 对应目录且文件名未改

## 文件

- [ ] 论文 PDF 字体嵌入、公式和图表清晰、页码正确
- [ ] 论文文件不超过 20 MB，且不压缩提交
- [ ] 支撑材料为单个 ZIP/RAR 且不超过 20 MB
- [ ] 解压后无缓存、密钥、临时文件或无关内容
- [ ] 三位队员分别完成最终人工复核
- [ ] 已核对竞赛官网、赛区和学校的最新通知与截止时间
